# 🛒 E-Commerce Sales Performance Dashboard | Excel

## 📌 Project Overview

The **E-Commerce Sales Performance Dashboard** is an interactive Excel dashboard designed to analyze e-commerce business performance and generate meaningful insights from sales and customer data.

This dashboard provides a comprehensive overview of orders, revenue, product performance, customer demographics, delivery time, and customer satisfaction. It helps understand business trends and supports data-driven decision-making through interactive visualizations and slicers.

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Track order quantity and revenue trends.
- Identify popular and best-performing products.
- Understand customer demographics and ordering preferences.
- Analyze delivery time and customer satisfaction.
- Present key business metrics through an interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning and Data Analysis
- Data Visualization

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Orders
- Total Quantity Sold
- Total Revenue
- Average Customer Rating
- Average Delivery Days

### 2. Sales Trend Analysis
- 13-week sales trend analysis.
- Comparison of sales amount and quantity over time.

### 3. Order Mode vs Gender Analysis
- Analyzes customer ordering preferences by gender.
- Compares different order channels such as App, Instagram, Partner App, Target.com, and Website.

### 4. Order Quantity Analysis
- Examines the distribution of order quantities.
- Identifies the frequency of different order sizes.

### 5. Popular Products Analysis
- Identifies popular products based on sales quantity.
- Analyzes product-wise contribution.
- Visualizes customer distribution by gender.

### 6. Customer Geographical Analysis
- Visualizes customer distribution across geographical locations.
- Helps understand customer concentration by region.

### 7. Delivery Time Analysis
- Analyzes the number of days taken to deliver orders.
- Helps understand delivery performance.

### 8. Customer Satisfaction Analysis
- Analyzes customer satisfaction ratings across different months.
- Helps identify trends in customer experience.

## 🎛️ Interactive Features

The dashboard includes interactive slicers that allow users to filter and explore data based on:

- Gender
- Order Mode
- Order Month

These filters help users explore different business dimensions and gain insights dynamically.

## 💡 Key Insights

The dashboard helps answer important business questions:

- How are sales performing over the 13-week period?
- Which products are most popular?
- Which ordering channels are preferred by customers?
- How does order quantity vary?
- Where are customers geographically concentrated?
- How long does delivery usually take?
- How does customer satisfaction change over time?
